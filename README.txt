Stalzone-server-selector (Stalzone Server Selector)
Сборка: дважды щёлкните build.bat (нужен .NET SDK). Готовый файл: dist\StalzoneServerSelector.exe
Это один exe-файл: его можно скопировать куда угодно, драйвер и список серверов уже внутри.

Фоновая работа (кнопка «Настройки» в программе):
  - запуск вместе с Windows (задача в Планировщике с правами администратора, без окна UAC);
  - при автозапуске окно скрыто, программа работает в трее (двойной щелчок по значку открывает окно);
  - автоматическое включение блокировки по последнему сохранённому выбору серверов;
  - кнопка закрытия сворачивает в трей, полный выход: значок в трее -> Выход.
Настройки и кэш хранятся в %LocalAppData%\StalzoneServerSelector
